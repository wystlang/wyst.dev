Wyst is an experimental ARM64 language and compiler exploring whether low-level code can remain readable without hiding machine behavior or cost.

I make the language and compiler decisions. Coding agents write the implementation.

Four checks examine the result. These checks are conformance tests, byte-identical kernel builds, fuzz tests, and QEMU fixtures.

My day job is building web interfaces. Wyst is where I pursue my interest in low-level programming and put my CS degree to use.
